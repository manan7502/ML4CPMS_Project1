## 💡 Key Architectural Concepts

### 1. The Classical Teacher (Main79)
* **Goal:** Establish a strong, leakage-safe baseline decision margin.
* **Input:** 13 meta-features generated by cross-validated out-of-fold SVM, NBSVM, and HistGradientBoosting.
* **Output:** Scaled and clipped decision margins $t \in [-6.0, +6.0]$.

### 2. The Neural Residual Ensemble (Main79)
* **Goal:** Learn subtle token-level nuances that linear classical models miss.
* **Input:** Token ID sequences + standardized meta-features.
* **Architecture:** 3-seed BiGRU ensemble (`seeds: 42, 137, 2024`).
* **Shrinkage:** $\text{score} = \text{teacher} + 0.025 \cdot \text{residual}$ (protects against overfitting).

### 3. Multi-Input Neural Fusion (Exp11)
* **Goal:** Extract orthogonal linguistic and structural signal.
* **Three Parallel Streams:**
  1. *Token Stream:* Multi-kernel 1D CNNs (`k=3, 5, 7`) over 128-dim embeddings.
  2. *Lexical Stream:* 1–6 character/word n-grams compressed via `TruncatedSVD` to 256 dimensions.
  3. *Structural Stream:* 58 engineered features (Shannon entropy across halves and quartiles, repetition rates, token length statistics).
* **Fusion:** Unified 128-dim dense representation with LayerNorm and Dropout.

### 4. Direct Probability Stacking (Final Winner)
* **Error Disagreement:** Exp11 correctly predicts 41 documents that Main79 misclassifies.
* **Optimal Blending:**
  $$p_{\text{blend}} = 0.86 \cdot p_{\text{Main79}} + 0.14 \cdot p_{\text{Exp11}}$$
* **Result:** Peak Kaggle public score of **0.9506**.
