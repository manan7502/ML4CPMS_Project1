NEURAL REPRESENTATION LEARNING EXPERIMENT SERIES
ML4CPMS Project 1 — Human vs Machine-Generated Text
======================================================

Purpose
-------
Systematically test whether CNNs, RNNs, Transformers, autoencoders,
contrastive learning, and multi-input neural networks can learn latent
document vectors that separate the two classes better than our current
classical pipeline.

CURRENT REFERENCE
-----------------
Main64 validation accuracy : 93.0266%
Main115 validation accuracy: 93.4535%
Main115 is the current local validation reference.

IMPORTANT
---------
- Run experiments one by one.
- Keep the canonical 80/20 stratified split, random_state=42.
- Do not submit to Kaggle unless explicitly decided later.
- For promising experiments, save the learned train/validation embeddings.
- Evaluate both the neural classifier and simple classifiers on the learned
  embedding whenever practical.
- The goal is not only accuracy: determine whether the learned latent vector
  contains genuinely useful/separable information.

----------

PHASE 1 — SINGLE REPRESENTATION ENCODERS
========================================

1. [✓] RAW TOKENS → CNN → LATENT VECTOR
    Input: token ID sequence
    Encoder: embedding + CNN
    Output: learned document vector z
    Evaluate: neural classifier, SVM(z), LR(z)

2. [✓] RAW TOKENS → BiGRU → LATENT VECTOR
    Input: token ID sequence
    Encoder: embedding + BiGRU + pooling
    Output: learned document vector z
    Evaluate: neural classifier, SVM(z), LR(z)

3. [✓] RAW TOKENS → TRANSFORMER → LATENT VECTOR
    Input: token ID sequence
    Encoder: embedding + Transformer + pooling
    Output: learned document vector z
    Evaluate: neural classifier, SVM(z), LR(z)

4. [✓] TF-IDF → SVD → MLP ENCODER
    Input: word/token TF-IDF
    Compression: SVD
    Encoder: MLP
    Output: learned vector z
    Evaluate: neural classifier, SVM(z), LR(z)

5. [✓] TRANSITION TF-IDF → SVD → MLP ENCODER
    Input: adjacent-token transition TF-IDF
    Compression: SVD
    Encoder: MLP
    Output: learned vector z
    Evaluate: neural classifier, SVM(z), LR(z)

6. [✓] STRUCTURAL FEATURES → MLP → LATENT VECTOR

    Encoder: MLP
    Output: learned vector z
    Evaluate: neural classifier, SVM(z), LR(z)

PHASE 4 — MAKE THE LATENT SPACE CLASS-SEPARABLE
================================================

Apply to the best promising architectures from Phases 1–3.

18. [✓] BEST MODEL + CROSS-ENTROPY
     Standard supervised classification objective.
     Baseline for learned latent space.

19. [✓] BEST MODEL + CROSS-ENTROPY + CONTRASTIVE LOSS
     L = L_CE + lambda * L_contrastive
     Encourage same-class vectors to be close and different-class
     vectors to be separated.

20. [✓] BEST MODEL + SUPERVISED CONTRASTIVE LEARNING
     Train the representation primarily for class separation.
     Evaluate the learned embedding independently with SVM/LR.

PHASE 8 — FINAL REPRESENTATION AUDIT
=====================================

For the strongest learned representations, measure:

29. [✓] EMBEDDING LINEAR SEPARABILITY
     SVM/LR accuracy and AUC using only z.

30. [✓] EMBEDDING DISTANCE ANALYSIS
     Within-class distance
     Between-class distance
     Between/within distance ratio

31. [✓] EMBEDDING NEAREST-NEIGHBOR ANALYSIS
     kNN class consistency in learned latent space.

32. [✓] EMBEDDING VISUALIZATION
     PCA / UMAP / t-SNE where useful.
     Check whether the two classes form visibly separated regions.

Geometry/classifier audit note:
- Do not run a full local-geometry/nonlinear-classifier study after every
  experiment during the broad 33-experiment sweep. That would multiply
  experiments and encourage repeated validation-set tuning.
- After the sweep, apply the detailed audit to the strongest saved
  representations, especially Exp13/Main133 and Exp11/Main131, plus any
  representation that proves complementary under strict OOF testing.
- Test kNN/local-neighborhood purity and local-distance features using
  training embeddings only when querying validation embeddings.
- Also test nonlinear classifiers on the strongest learned vectors
  (for example RBF-style models or small nonlinear heads). Any model
  selection or fusion that learns from predictions should use strict OOF
  predictions where appropriate.

33. [✓] FINAL COMPARISON AGAINST MAIN115
     Compare the best learned representation and any final fusion
     against the 93.4535% Main115 validation reference.


DECISION RULE
=============
After each experiment:

1. Record validation accuracy and AUC.
2. Record whether SVM/LR on the learned vector performs well.
3. Check whether the representation adds information beyond existing
   classical features.
4. If clearly weak, mark the branch [-] and do not spend excessive time
   tuning it.
5. If promising, carry it into the next phase.
6. Only the strongest representations proceed to the expensive phases.

EXPERIMENT 26 RESULT — EXP25 SHARED LATENT + MAIN64 TEACHER DISTILLATION
=======================================================================

Status: [✓] Completed / [-] Retired standalone

Configuration:
- Seed: 146
- Dataset: 10,536
- Train/validation: 8,428 / 2,108
- Canonical split: train_test_split(test_size=0.20, stratify=y, random_state=42)
- Architecture inherited from Exp25/Main145:
  raw tokens + word TF-IDF + transition TF-IDF + structural features
  → shared 128-D latent vector
- Max sequence length: 384
- Vocabulary size: 13,858
- Word TF-IDF: 1–3 grams, min_df=2, max_df=0.995,
  max_features=60,000, sublinear TF
- Word SVD: 256 components; explained variance 17.4227%
- Transition TF-IDF: adjacent-token transitions, 1–2 grams,
  max_features=60,000, sublinear TF
- Transition SVD: 256 components; explained variance 14.5204%
- Structural input: 62-D reconstructed compact structural/statistical features
- Token embedding: 96-D
- BiGRU hidden: 96-D per direction
- Latent vector: 128-D
- Trainable parameters: 1,684,960
- Objective:
  BCE + reconstruction + 0.1 × supervised contrastive
  + 0.15 × Main64 teacher-score regression
- Contrastive margin: 0.2
- Batch size: 32
- Best epoch: 2
- Runtime: ~45.3 s
- Main64 teacher: leakage-safe train-only OOF scores for 8,428 training rows
  plus canonical 2,108 validation scores

Results:
- Neural validation accuracy: 88.5199%
- Neural validation AUC: 0.9506
- SVM on learned z: 88.0455%
- SVM AUC: 0.9519
- Logistic Regression on learned z: 88.3302%
- LR AUC: 0.9523
- Between-class centroid distance: 6.3162
- Within-class mean distance: 4.4808
- Between/within ratio: 1.4096

Training behavior:
- Epoch 1: val accuracy 86.1480%, AUC 0.9374, val loss 0.7316.
- Epoch 2: val accuracy 88.5199%, AUC 0.9506, best validation loss 0.6373.
- Epoch 3: val accuracy 88.2353%, AUC 0.9457, while validation loss increased
  to 0.8634.
- Epochs 4–8 continued to show lower training loss but unstable/worse
  validation loss; early stopping occurred after epoch 8.
- Teacher RMSE stayed around 0.36, with no corresponding improvement in
  the learned classification representation.

Comparison with Exp25/Main145:
- Exp25 neural validation accuracy: 89.0892%.
- Exp26 neural validation accuracy: 88.5199%.
- Exp25 neural AUC: 0.9510.
- Exp26 neural AUC: 0.9506.
- Exp25 SVM-on-z: 88.5674%.
- Exp26 SVM-on-z: 88.0455%.
- Exp25 LR-on-z: 88.4250%.
- Exp26 LR-on-z: 88.3302%.
- Exp25 between/within ratio: 2.5216.
- Exp26 between/within ratio: 1.4096.

Interpretation:
- Adding frozen Main64 teacher-score distillation did not improve the Exp25
  representation under this configuration.
- Neural accuracy decreased by about 0.57 percentage points.
- SVM-on-z decreased by about 0.52 percentage points.
- LR-on-z decreased by about 0.09 percentage points, while LR AUC remained
  0.9523.
- The geometry ratio dropped substantially from 2.5216 to 1.4096.
- Therefore this teacher-distillation setup is not a better standalone latent
  representation than Exp25.
- This does NOT establish that Main64 information is useless for fusion:
  teacher outputs may still be complementary when combined through strict OOF
  predictions instead of being forced into the latent during representation
  learning.

Decision:
- Retire Exp26 as a standalone representation-learning approach.
- Do not spend time tuning the teacher weight during the broad 33-experiment
  sweep.
- Retain main146_embeddings.npz and main146_best.pt for possible later
  strict-OOF fusion/complementarity testing.
- Proceed to Experiment 27: LEARNED VECTOR + MAIN115 SPECIALIST OUTPUTS.



EXPERIMENT 27 RESULT — MAIN145 LEARNED VECTOR + MAIN115 SPECIALIST OUTPUTS
============================================================================

Status: [✓] Completed / [-] Retired for this simple fusion configuration

Configuration:
- Experiment: Main147 / Exp27
- Canonical train/validation split: 8,428 / 2,108
- Learned representation: main145_embeddings.npz
- z_train shape: 8,428 × 128
- z_val shape: 2,108 × 128
- Main115 specialist outputs: 5 probabilities per document
- Specialists:
  LR_C1, HGB_small, HGB_medium, RandomForest, ExtraTrees
- Fused representation: 128-D learned z + 5 Main115 specialist probabilities
  = 133 dimensions
- Main115 training probabilities are the strict OOF specialist outputs.
- Validation probabilities correspond to the canonical validation order.
- Classifier probes: Logistic Regression and Linear SVM
- No Kaggle submission.

Results:
- LR on Main145 z only: 88.9943%, AUC 0.9550
- LR on Main115 specialist outputs only: 92.7419%, AUC 0.9838
- LR on fused 133-D representation: 89.3738%, AUC 0.9639
- SVM on Main145 z only: 88.9469%, AUC 0.9558
- SVM on Main115 specialist outputs only: 92.7419%, AUC 0.9838
- SVM on fused 133-D representation: 89.5636%, AUC 0.9605
- Main115 frozen specialist-consensus rule: 93.4535%

Complementarity diagnostics:
- Main115 error rows where LR on learned z is correct: 146 / 232 = 62.93%
- Main115 error rows where SVM on learned z is correct: 151 / 233 = 64.81%
- LR fused prediction changes versus z-only: 14 rows; 11 changes correct.
- SVM fused prediction changes versus z-only: 19 rows; 16 changes correct.

Interpretation:
- The learned Main145 representation contains information that differs from
  the Main115 specialist outputs: on Main115-error rows, the learned-vector
  classifier is correct substantially more often than chance.
- However, simple feature concatenation with LR/SVM does not exploit that
  complementarity effectively. The fused classifiers remain far below the
  frozen Main115 rule of 93.4535%.
- The specialist-output-only probe reaches 92.7419%, confirming that the five
  Main115 specialist predictions contain strong information, but this probe

- Epoch 4: train acc 93.59%, val acc 82.50%, AUC 0.9435; best validation
  total loss.
- Epoch 5: train acc 96.73%, val acc 83.16%, AUC 0.9461, but validation
  total loss increased, so it was not selected.
- Epochs 6–11: training accuracy reached ~99.7% while validation loss remained
  substantially worse. Early stopping occurred after epoch 11.
- The reconstruction term became very small and continued improving, while
  classification loss dominated the total objective. Thus the decoder did
  not prevent the classifier from overfitting.

Interpretation:
- The supervised autoencoder successfully learned a nontrivial latent
  representation: LR/SVM AUC is about 0.944 and the between/within ratio is
  2.6664.
- However, the representation is much weaker than the strongest learned
  representations. Exp13/Main133 reached LR-on-z 90.7970% with AUC 0.9695,
  while Exp22 reaches only 82.4478% with AUC 0.9437.
- The latent geometry is not the problem by itself; the representation has
  measurable class structure, but substantially less useful information than
  the strongest multi-input representations.
- Adding the classification objective to reconstruction did not make this
  autoencoder a competitive standalone classifier.
- The best validation AUC appears at epoch 7 (0.9503), and threshold accuracy
  peaks later at epoch 10 (83.44%), but model selection remains based on the
  predefined best total validation loss at epoch 4. Do not retune to these
  later validation peaks during the broad sweep.
- Compared with Experiment 21, Experiment 22 is computationally viable on the
  laptop because it reconstructs only the 512-D SVD representation. The
  original 60,000-D direct-reconstruction architecture should not be rerun
  locally.

Decision:
- Retire Exp22 as a standalone classifier.
- Do not hyperparameter-tune the SVD dimension, reconstruction weight, or
  classification weight yet.
- Retain main142_embeddings.npz and main142_best.pt for possible later
  complementary strict-OOF fusion if needed.
- Proceed to Experiment 23: TF-IDF + CONTRASTIVE SUPERVISED AUTOENCODER.
- Exp23 should keep the same memory-safe SVD(512) bottleneck rather than
  returning to direct 60,000-D dense reconstruction.
