1. The Six Features Added in Stage 2

1.1 Distinct Bigram & Trigram Ratios

Measures the uniqueness of consecutive token transitions across the entire essay:

$$\text{Distinct\_Bi} = \frac{|\{(t_i, t_{i+1}) : 1 \le i < L_d\}|}{L_d - 1}, \quad \text{Distinct\_Tri} = \frac{|\{(t_i, t_{i+1}, t_{i+2}) : 1 \le i < L_d - 1\}|}{L_d - 2}$$

Why it is added: Autoregressive language models generate text by iteratively sampling the next token conditioned on recent context attention. Under standard temperature parameters, decoders frequently fall into cyclic local phrasing patterns and repeat transitional idioms. Human writers demonstrate significantly higher syntactic and semantic variability in their local token transitions.

1.2 Subword Tokenizer Geometry (\(\mu_{\text{token\_id}}, \sigma_{\text{token\_id}}\))

In modern subword tokenization schemes (such as Byte-Pair Encoding or WordPiece), token integer IDs are assigned in strict decreasing order of corpus unigram frequency:

  • Low Token IDs (\(< 3,000\)): Universal functional words ("the", "is", "which"), punctuation, and frequent prefixes.
  • High Token IDs (\(> 10,000\)): Rare, domain-specific, morphological inflections, and idiosyncratic expressions.

We compute the empirical first and second central moments of the token ID sequence:

$$\mu_{\text{token\_id}} = \frac{1}{L_d} \sum_{i=1}^{L_d} t_i, \quad \sigma_{\text{token\_id}} = \sqrt{\frac{1}{L_d} \sum_{i=1}^{L_d} (t_i - \mu_{\text{token\_id}})^2}$$

Why it is added: Top-\(p\) nucleus sampling cuts off the tail of the vocabulary distribution during LLM generation. Human writers uninhibitedly deploy rare tail tokens, shifting the mean and spread of token IDs upward.

1.3 Vocabulary Quartile Ratios (\(Q_1, Q_4\))

Quantifying the exact boundary density of functional vs. tail tokens:

$$Q_1 = \frac{|\{t_i : t_i \le 3000\}|}{L_d}, \quad Q_4 = \frac{|\{t_i : t_i \ge 10000\}|}{L_d}$$

Key Finding: Token ID Geometry As an Independent Signal
Because TF-IDF normalizes words based strictly on corpus term frequency without semantic rank knowledge, the tokenizer's pre-trained frequency index provides an orthogonal signal. Pairing token ID moments with local n-gram diversity allowed the Linear SVM to break the 90% boundary cleanly.
