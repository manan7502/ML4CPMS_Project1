Why Feature Selection Succeeded: The Core Intuition

Bag-of-Words and high-dimensional TF-IDF vectors excel at memorizing topical vocabulary and short recurring phrase templates. However, LLM authorship attribution fundamentally hinges on structural generative artifacts that Bag-of-Words representations are mathematically blind to:

  • Information-Theoretic Constraints (Stage 1): Softmax temperature truncation (\(T < 1.0\)) and nucleus sampling (\(p < 1.0\)) artificially compress the token probability distribution, yielding distinct entropy and vocabulary breadth characteristics independent of essay length.
  • Autoregressive Markovian Phrasing Loops (Stage 2): Decoders frequently cycle through locally repetitive transition states, resulting in lower distinct bigram/trigram ratios and an underrepresentation of tail subword vocabulary.
  • Corpus-Level Bayesian Likelihood Bias (Stage 3): Generative models systematically overuse certain token families. Pooling these unigram likelihood ratios at the document level provides a continuous global measure of machine bias that enabled the single largest performance jump (+0.95%).
  • Temporal Dynamics & Non-Poisson Burstiness (Stage 4): Human memory retrieval is bursty—concepts appear in dense temporal clusters separated by long intervals. LLM generation follows more uniform, stationary inter-arrival dynamics.
Key Engineering Breakthrough: Numerical Conditioning
Concatenating dense statistics with a 250,000-dimensional sparse TF-IDF matrix initially caused LibLinear coordinate descent to diverge when using StandardScaler, and squashed signals when using row-wise \(L_2\) normalization. The resolution was applying MaxAbsScaler inside each fold, scaling dense statistics into \([-1, 1]\) to match TF-IDF coordinate magnitudes. Full details are documented in Scaling & Engineering.
