1. The Theoretical Breakthrough: Why Spectral SVD Succeeded Where HMMs Failed

1.1 The Failure of Discrete HMMs (-0.038% Delta)

In preliminary experiments, an unsupervised Hidden Markov Model (HMM) was fitted via Baum-Welch Expectation-Maximization to discover latent Part-of-Speech (POS) categories. However:

  • Soft posterior state distributions \(\gamma_t(k) = P(z_t = k \mid d)\) degenerated into blurred unigram histograms.
  • The inferred discrete state transitions were completely redundant with cumulative 1–5 gram TF-IDF, adding 185 seconds of EM training time while reducing accuracy by -0.038%.

1.2 The Spectral Solution: Continuous Syntactic Manifold

Instead of non-convex discrete latent state clustering, we construct the empirical transition matrix \(\mathbf{P} \in \mathbb{R}^{V \times V}\) over the functional syntax vocabulary (top \(K = 500\) tokens):

$$P_{ij} = P(t_{k+1} = j \mid t_k = i) = \frac{\text{count}(t_k = i \to t_{k+1} = j)}{\sum_m \text{count}(t_k = i \to t_{k+1} = m)}$$

Computing the Truncated Singular Value Decomposition (SVD) on \(\mathbf{P}\):

$$\mathbf{P} \approx \mathbf{U}_{12} \mathbf{\Sigma}_{12} \mathbf{V}_{12}^T$$

projects every functional token into a continuous 12-dimensional coordinate:

$$\mathbf{e}(t) \in \mathbb{R}^{12}$$

2. The 16 Trajectory Invariants Added in Stage 5

As an author writes, the sequence of tokens forms a continuous path \(\mathbf{X}_{\text{traj}} = [\mathbf{e}(t_1), \dots, \mathbf{e}(t_n)]^T\) traversing this 12-dimensional syntactic space. We compute 16 invariant descriptors:

Feature Name Dimension Mathematical Formulation Linguistic & Physical Intuition
Manifold Centroid 12 features $$\boldsymbol{\mu} = \frac{1}{n} \sum_{i=1}^n \mathbf{e}(t_i)$$ Centers the document's syntactic grammar within the 12-D coordinate space.
Syntactic Dispersion 1 feature $$R_g^2 = \frac{1}{n} \sum_{i=1}^n \|\mathbf{e}(t_i) - \boldsymbol{\mu}\|^2$$ Radius of Gyration: Structural breadth of grammatical exploration across the essay.
Mean Velocity Step Length 1 feature $$\mu_v = \frac{1}{n-1} \sum_{i=1}^{n-1} \|\mathbf{e}(t_{i+1}) - \mathbf{e}(t_i)\|$$ Average jump distance between consecutive grammatical transitions.
Velocity Step Variance 1 feature $$\sigma_v = \text{std}(\|\mathbf{e}(t_{i+1}) - \mathbf{e}(t_i)\|)$$ Pacing Jitter: Humans vary their syntactic pacing; LLMs generate with uniform transition tempo.
Syntactic Tortuosity 1 feature $$\tau = \frac{\|\mathbf{e}(t_n) - \mathbf{e}(t_1)\|}{\sum_{i=1}^{n-1} \|\mathbf{v}_i\| + \epsilon}$$ Arc-to-Chord Ratio: Measures goal-directed grammatical development vs. local autoregressive wandering.

3. Strict Out-of-Fold (OOF) Validation Audit: Zero Leakage Verification

To verify that the feature does not rely on transductive data exposure, we conducted a strict 100% In-Fold Manifold Learning audit:

  • The top-500 functional vocabulary, bigram transition matrix, and Truncated SVD are fitted solely on the 80% training split (\(N \approx 8,428\)).
  • Validation documents are projected strictly using the frozen training manifold.

4. Resolving Class Population Asymmetry

The dataset contains 6,837 Machine texts (64.89%) vs. 3,699 Human texts (35.11%). In unweighted training, the separating hyperplane shifts toward the minority class, depressing Human Recall to 88.65%.

By incorporating cost-sensitive inverse class weights (\(w_c = \frac{N}{2 N_c}\)) into Stage 5:

  • 5-Fold Accuracy jumps to 91.9419% (+0.64% over Stage 4).
  • Macro F1 reaches 91.21%.
  • Human Recall surges from 88.65% to 91.00% (+2.35% boost) without degrading machine recall (92.38%).
