Scientific Findings Across the 4 Experiments

1. Why the Base Unsupervised HMM (Exp 1) Saturated (-0.038%)

In Experiment 1, a 10-state CategoricalHMM was fit to induce latent POS categories. While the latent states displayed intuitive linguistic tendencies, its document-level unigram tag frequencies failed to improve the linear margin.

Reason (Linear Subsumption): In a Linear SVM with 248,349 cumulative 1-to-5 grams, common grammatical transitions (e.g. [the, word], [in, which]) are already explicit coordinates with independent weights. An unsupervised HMM's static tag proportions are essentially a low-rank linear projection of token bigrams; the linear classifier has already learned the optimal weights directly from the sparse \(N\)-gram space.

2. Why Dual Class-Conditional HMMs (Exp 2) Succeeded (+0.133%)

In Experiment 2, we separated the corpus and trained two independent generative HMMs: \(\lambda_A\) on Human text and \(\lambda_B\) on Machine text.

For each document, we computed the normalized forward log-likelihoods \(\mathcal{L}_A(d)\) and \(\mathcal{L}_B(d)\), yielding the Bayesian Syntactic Likelihood Ratio:

$$\Delta \mathcal{L}_{\text{syntax}}(d) = \mathcal{L}_B(d) - \mathcal{L}_A(d)$$

This directly evaluates which grammar model generated the observed transition flow. Human essays strongly favored \(\lambda_A\) (\(\text{Mean } \Delta \mathcal{L} = -0.1261\)), while Machine essays favored \(\lambda_B\) (\(\text{Mean } \Delta \mathcal{L} = +0.0429\)). This cleanly separated difficult boundary cases, boosting accuracy to 91.44% and tightening standard deviation to \(\pm 0.30\%\).

3. Why the Grammar Skeleton (Exp 3) Failed (-0.456%)

In Experiment 3, we isolated the top 150 functional tokens and replaced all open-class content tokens with a generic token C.

The Combinatorial Noise Trap
Collapsing thousands of distinct content words into a single dummy token C created hyper-frequent, low-information sequences such as C C C C and C 42 C C. Adding 15,000 sparse skeleton features diluted the primary lexical signal and shifted the SVM hyperplane away from discriminative boundaries.

4. The Breakthrough: Spectral Syntactic Trajectory Dynamics (Exp 4, +0.437%)

In Experiment 4, we bypassed iterative Baum-Welch training by applying Truncated SVD directly to the row-normalized bigram transition probability matrix \(P(w_{t+1} \mid w_t)\). This extracted a continuous 12-dimensional Syntactic Manifold \(\mathbf{e}_w \in \mathbb{R}^{12}\).

As an author writes, their essay traces a continuous trajectory \(\mathbf{e}_1, \dots, \mathbf{e}_n\) through this 12-dimensional syntactic space. We modeled the physical dynamics of this trajectory:

  • Syntactic Velocity Steps: \(\mathbf{v}_t = \mathbf{e}_{t+1} - \mathbf{e}_t\)
  • Velocity Step Variance: \(\sigma(\|\mathbf{v}_t\|)\)
  • Syntactic Tortuosity: Ratio of net displacement to total path length \(\frac{\|\mathbf{e}_n - \mathbf{e}_1\|}{\sum \|\mathbf{v}_t\|}\)
  • Manifold Radius of Gyration: \(\frac{1}{n} \sum \|\mathbf{e}_t - \boldsymbol{\mu}_e\|^2\)

Because human cognition shifts smoothly between syntactic frames whereas autoregressive decoders hop according to softmax transition probabilities, these continuous physical trajectory metrics achieved a +0.437% gain, establishing a new state-of-the-art of 91.74%!
