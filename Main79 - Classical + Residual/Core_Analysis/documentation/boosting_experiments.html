1. The Four Boosting Paradigms Investigated

In text classification, boosting faces two opposite extremes: tree boosting directly on 250,000 sparse columns is computationally prohibitive, while sample-reweighted linear boosting is sensitive to label noise. We evaluated four targeted formulations:

Paradigm 1

Linear AdaBoost

Sequential exponential sample reweighting on LinearSVC hyperplanes.

Paradigm 2

Standalone Modern GBDTs

LightGBM, CatBoost, and XGBoost on the 34 dense physical features alone.

Paradigm 3

Two-Stage Residual Boosting

GBDT trained on \([\mathbf{x}_{\text{dense}} \mid m_{\text{Linear}}]\) to learn boundary corrections.

Paradigm 4 (SOTA)

Hybrid Probability Stacking

Calibrated blending: \(0.85 P_{\text{Linear}} + 0.15 P_{\text{GBDT}}\) reaching 92.22%.

2. Why Linear AdaBoost Collapses on High-Dimensional Text

Testing AdaBoostClassifier(LinearSVC) across \(M \in \{1, 2, 3, 5, 8\}\) produced a severe performance drop:

  • Single LinearSVC Baseline: 91.84%
  • Linear AdaBoost (\(M=2\)): 78.18% (-13.66%)
  • Linear AdaBoost (\(M=5\)): 82.45% (-9.39%)
  • Linear AdaBoost (\(M=8\)): 84.30% (-7.54%)
The Exponential Loss Overfitting Phenomenon (Hastie et al., 2009)
AdaBoost updates sample weights exponentially: \(w_i \leftarrow w_i \exp(-\alpha_m y_i h_m(\mathbf{x}_i))\). In text corpora containing ambiguous or borderline essays (human text adopting structured analysis or LLMs imitating informal prose), AdaBoost concentrates massive weights onto these noisy outliers. In 250,000 dimensions, forcing a linear hyperplane to fit extreme outliers tilts the boundary, severely degrading accuracy across the rest of the corpus.

3. Standalone GBDTs on the 34 Dense Descriptors Alone (90.7%)

We trained modern gradient boosted decision trees strictly on the 34 engineered physical descriptors, completely stripping away all TF-IDF N-grams:

Top Feature Importances Driving the Trees:

  1. Syntactic_Dispersion (\(R_g^2\), manifold radius of gyration).
  2. Mean_Machine_Affinity and Max_Machine_Affinity (Bayesian log-DF likelihood).
  3. Root_TTR_Guiraud and Shannon_Entropy (information-theoretic richness).
  4. Token_Recurrence_Burstiness (\(B\), non-Poisson cognitive inter-arrival clustering).

4. The Breakthrough: Calibrated Hybrid Probability Stacking (92.22%)

Linear models excel at pooling weak lexical signals across 250,000 N-gram dimensions, while GBDTs excel at modeling non-linear thresholds and interactions among dense physical metrics.

$$\hat{P}(\text{Machine} \mid \mathbf{x}) = (1 - w) \cdot \frac{1}{1 + e^{-m_{\text{Linear}}(\mathbf{x})}} + w \cdot P_{\text{GBDT}}(\mathbf{x}_{\text{dense}})$$

A sensitivity sweep revealed the optimal weighting at \(w = 0.15\) (85% Linear Margin + 15% CatBoost/LightGBM Dense Posterior).
