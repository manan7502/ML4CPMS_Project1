End-to-End System Architecture: Classical Feature Pipeline & Residual Stacking

The visual below illustrates the complete, leak-free machine learning architecture developed in this program—from raw token sequences through dual sparse-dense feature extraction, cost-sensitive Level-1 base models, and a PyTorch Deep Residual Stacker with disagreement arbitration reaching the 92.49% project record:

Step 1: Dual Feature Branching

Separates lexical token n-grams (~250k sparse dims) from 34 continuous physical invariants (entropy, burstiness, syntax SVD) to prevent dense signals from drowning.

Step 2: Numerical Conditioning

Applies in-fold MaxAbsScaler to bound dense features into \([-1, 1]\), preventing LibLinear coordinate descent divergence when concatenated with TF-IDF.

Step 3: Base Models & Error Audit

LinearSVC establishes 91.89% baseline. A forensic error audit diagnosed 521 false negatives and 12.7% short-text error rate.

Step 4: Residual Stacking & Fixes

Gated features, LightGBM (93.65%), and PyTorch Deep ResNet Stacker eliminate 228 errors, setting the all-time record at 94.0585% SOTA.

Why Feature Selection & Hybrid Stacking Succeeded

  • Information-Theoretic Constraints (Stage 1): Nucleus sampling truncates tail vocabulary, giving machines constrained entropy.
  • Autoregressive Phrasing Loops (Stage 2): Decoders cycle through local bigram/trigram repetition states.
  • Corpus-Level Bayesian Affinity (Stage 3): Pooling unigram machine log-odds ratios yields the single largest classical leap (+0.95%).
  • Cognitive Burstiness Dynamics (Stage 4): Human associative memory retrieval is non-Poisson and bursty; LLM generation is stationary.
  • Continuous Syntactic Geometry (Stage 5): Embedding the bigram syntax transition matrix via SVD models the physical tortuosity and pacing jitter of human essays vs. machine autoregression (+0.44% SOTA).
  • Resolving Population Asymmetry (Bagging Study): Cost-sensitive inverse class weights correct the 65:35 majority bias, surging human recall from 88.65% to 91.00% (+2.35%).
  • Hybrid Classical + GBDT Stacking (Boosting Study): Blending the high-dimensional linear N-gram posterior (\(0.85 P_{\text{Linear}}\)) with non-linear tree boosting on the 34 dense physical features (\(0.15 P_{\text{CatBoost}}\)) achieved 92.22% 5-fold CV accuracy across all 10,536 essays.
  • Out-of-Fold Residual Stacking with Neural Heads (Neural Stacking SOTA): Replacing static linear probability blending with a deep residual neural network (ResNet blocks with LayerNorm, GELU, and Dropout) taking continuous margins, tree logits, and inter-model disagreement alongside physical descriptors pushes performance to an all-time peak of 92.49% 5-fold CV accuracy (±0.34%), eliminating weak-fold collapses and boosting Macro F1 to 91.81%.
Key Engineering Breakthrough: Numerical Conditioning
Concatenating dense statistics with a 250,000-dimensional sparse TF-IDF matrix initially caused LibLinear coordinate descent to diverge when using StandardScaler, and squashed signals when using row-wise \(L_2\) normalization. The resolution was applying MaxAbsScaler inside each fold, scaling dense statistics into \([-1, 1]\) to match TF-IDF coordinate magnitudes. Full details are documented in Scaling & Engineering.
