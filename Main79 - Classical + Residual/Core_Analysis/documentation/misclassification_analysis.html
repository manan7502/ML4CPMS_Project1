Misclassification Debugging & Stacking Pipeline Architecture

The diagram below illustrates the multi-stage error resolution pipeline—branching from the Stage 5 baseline into feature-level stabilization (Fixes 1 & 2) and non-linear Level-2 stacked arbitration (Fixes 3 & 4):

1. The Forensic Audit: Three Structural Failure Modes

In the Stage 5 balanced model, the decision hyperplane achieved an overall accuracy of 91.89%, leaving 854 misclassified documents. Segmenting these errors across directionality, document geometry, and confidence revealed three fundamental flaws:

Failure Mode 1: Class-Imbalance Penalty Distortion (521 vs. 333)

Over 61.0% of all mistakes (521 out of 854) were Machine documents misclassified as Human (False Negatives). This was directly induced by class_weight='balanced', which imposes a 1.85× higher penalty on Human errors (\(w_A = 1.424\) vs. \(w_B = 0.770\)). The optimization shifted the decision boundary excessively into the Machine distribution, incorrectly pushing hundreds of borderline Machine texts across the zero margin.

Failure Mode 2: Sequence Length Epistemic Fragility

Document length stratification exposed an extreme disparity:

  • Long Documents (\(L \in [244, 994]\)): Near-flawless 97.80% accuracy (only 46 errors out of 2,094 documents!).
  • Short Documents (\(L \le 61\)): Severe 12.70% error rate (273 errors out of 2,149 documents!).

Root Cause: In a 30-token essay, sparse n-gram overlap is nearly nonexistent, while continuous statistical aggregates (Shannon entropy, radius of gyration, burstiness, tortuosity) suffer extreme small-sample estimation variance, throwing the linear decision score.

Failure Mode 3: Pathological Short-Text Outliers

The most confident errors occurred on short texts where a linear sum \(\sum w_i x_i + b\) overreacted to isolated cue tokens:

  • Doc 8821 (Length 33): True Human classified as Machine with an extreme margin of +1.930.
  • Doc 207 (Length 35): True Machine classified as Human with an extreme margin of -1.487.
  • Doc 9031 (Length 46): True Machine classified as Human with an extreme margin of -1.475.

2. The Four Progressive Fixes

Fix 1: Threshold & Margin Probability Calibration

Objective: Mitigate Failure Mode 1 by mapping raw uncalibrated SVM margins to true posterior probabilities using in-fold Platt scaling:

$$P(y=1|\mathbf{x}) = \frac{1}{1 + \exp(A \cdot f(\mathbf{x}) + B)}$$

Optimizing the decision threshold \(\tau^*\) on training folds re-aligns predictions with the natural ~65/35 class prior. Accuracy rises to 91.94%, converting raw margins into smooth probability inputs for downstream ensembles.
Notebook Reference: 01_Fix_Threshold_Calibration.ipynb

Fix 2: Length-Conditioned & Gating Features

Objective: Mitigate Failure Mode 2 by stabilizing statistical features across short sequences. We introduce logarithmic length transformations (\(\log(1+L_d), 1/\sqrt{L_d}\)) and hyperbolic tangent variance gating:

$$\mathbf{f}_{\text{gated}} = \mathbf{f}_{\text{dense}} \cdot \tanh\left(\frac{L_d}{50}\right)$$

For short documents (\(L_d < 30\)), features decay smoothly toward zero, preventing noisy statistical estimators from destabilizing the margin.

  • Accuracy increases to 92.06% (Macro F1: 91.39%).
  • Short-document error rate (\(L \le 61\)) drops from 12.70% to 12.10%.
  • Long-document accuracy is completely preserved (45 errors, 97.85% accuracy).

Notebook Reference: 02_Fix_Length_Conditioned_Gating.ipynb

Fix 3: Non-Linear Gradient Boosted Ensemble (LightGBM)

Objective: Overcome linear boundary constraints by training gradient boosted decision trees over a 67-dimensional tabular representation combining Stage 5 Linear margins, 34 dense physical descriptors, 30 TruncatedSVD components, and length scales.

Trees naturally formulate conditional hierarchical splits (e.g. IF Length ≤ 60 AND Token_0 == 0 THEN ...).

  • Accuracy leaps to 93.65% (+1.76% over baseline).
  • 185 misclassifications eliminated (total errors drop from 854 to 669).
  • False negatives plummet from 521 down to 328 (-193 errors!).

Notebook Reference: 03_Fix_Nonlinear_Gradient_Boosted_Ensemble.ipynb

Fix 4: Deep Neural Residual Stacking Architecture (PyTorch)

Objective: Resolve multi-modal representation disagreements and pathological outlier margins using a PyTorch Deep Residual Stacker with LayerNorm, GELU, and 2× Residual Blocks with Skip Connections (\(x + \text{Residual}(x)\)):

$$\mathbf{h}_0 = \text{GELU}(\text{LayerNorm}(\mathbf{W}_{\text{in}} \mathbf{x} + \mathbf{b}_{\text{in}}))$$ $$\mathbf{h}_1 = \mathbf{h}_0 + \text{ResBlock}_1(\mathbf{h}_0), \quad \mathbf{h}_2 = \mathbf{h}_1 + \text{ResBlock}_2(\mathbf{h}_1)$$ $$\hat{y} = \sigma(\mathbf{W}_{\text{out}} \mathbf{h}_2 + b_{\text{out}})$$

Fusing continuous linear margins, logistic probability approximations, and 15 SVD latent coordinates allows the network to smoothly arbitrate subtle edge cases:

  • All-Time SOTA Accuracy: 94.06% (+2.17% over baseline).
  • Macro F1: 93.54%.
  • 228 errors eliminated (total errors down to 626).
  • Balanced sensitivity: 93.76% Human Recall and 94.22% Machine Recall.

Notebook Reference: 04_Fix_Neural_Residual_Stacking.ipynb
